## The REGEN_VECTORS pattern

MO-006 embedded the regeneration mechanism inside the failing tests. To bless a
future intentional output change:

```
REGEN_VECTORS=1 cargo test test_epoch_key_derivation_vectors -- --exact
```

Inspect the resulting JSON diff. Commit only if the change matches the intended
decision. Do **not** use this mechanism to mask genuine bugs — if a test fails
for reasons other than an intentional crypto-output change, fix the code instead
of rewriting vectors.
